專案搬移指令面板（PowerShell）

給「整個專案搬到新電腦/新環境」使用。請照 Step 1 → Step 10 順序執行。

Step 1

設定專案路徑（可搬移）

先設定專案根目錄變數，後面所有指令都可重複使用。

$ROOT = "C:\path\to\blind_glasses"
Set-Location $ROOT
已複製
Step 2

檢查必要工具

確認 Python / pip / ngrok 可用；沒有就先安裝。

python --version
pip --version
ngrok version
已複製
Step 3

建立與啟用 Python 虛擬環境

在新環境建議固定使用 venv，避免套件衝突。

Set-Location "$ROOT\server"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
已複製
Step 4

安裝 server 相依套件

先找 requirements，再 fallback 手動安裝常用套件。

Set-Location "$ROOT\server"
if (Test-Path .\requirements.txt) {
  pip install -r .\requirements.txt
} else {
  pip install fastapi uvicorn requests python-dotenv
}
已複製
Step 5

設定 ngrok token（新環境只需一次）

第一次在新機器使用 ngrok 時要先設定。

ngrok config add-authtoken <YOUR_TOKEN>
已複製
Step 6

啟動 FastAPI Server（視窗 A）

此視窗保持開啟，提供 API。

Set-Location "$ROOT\server"
.\.venv\Scripts\Activate.ps1
python -m uvicorn main:app --host 0.0.0.0 --port 5000
已複製
Step 7

啟動 ngrok（視窗 B）

另外開一個 PowerShell 視窗執行並保持在線。

Set-Location $ROOT
ngrok http 5000
已複製
Step 8

抓 ngrok 公開網址（視窗 C）

從本機 ngrok API 讀取 `Public URL` 與 Health URL。

$t = (Invoke-RestMethod -UseBasicParsing 'http://127.0.0.1:4040/api/tunnels' -TimeoutSec 5).tunnels
$u = ($t | Where-Object { $_.public_url -like 'https://*' } | Select-Object -First 1).public_url
if (-not $u) { $u = ($t | Select-Object -First 1).public_url }
"Public URL: $u"
"Health URL: $u/health"
已複製
Step 9

驗證健康檢查

把下面網址中的 `xxxxx` 換成你剛抓到的 ngrok 子網域。

start https://xxxxx.ngrok-free.app/health
已複製
Step 10

Firmware 端燒錄與監看（可選）

若同時搬移 firmware 環境，可直接跑這組。

Set-Location "$ROOT\firmware"
pio run -t upload
pio device monitor -b 115200
已複製
Troubleshoot

常見問題快速修復

啟動失敗時可先跑以下命令再重試 Step 6。

Set-Location "$ROOT\server"
.\.venv\Scripts\Activate.ps1
pip install --upgrade pip
pip install -r .\requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 5000 --reload
已複製
All-in-One

新環境一鍵初始化（分兩個視窗）

先在視窗 A 執行 server 初始化與啟動，再在視窗 B 執行 ngrok；最後可在任一視窗貼 health 檢查。

# 視窗 A：Server 初始化 + 啟動
$ROOT = "C:\path\to\blind_glasses"
Set-Location "$ROOT\server"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
if (Test-Path .\requirements.txt) {
  pip install -r .\requirements.txt
} else {
  pip install fastapi uvicorn requests python-dotenv
}
python -m uvicorn main:app --host 0.0.0.0 --port 5000

# 視窗 B：ngrok
$ROOT = "C:\path\to\blind_glasses"
Set-Location $ROOT
ngrok http 5000

# 任一視窗：抓公開網址 + health
$t = (Invoke-RestMethod -UseBasicParsing 'http://127.0.0.1:4040/api/tunnels' -TimeoutSec 5).tunnels
$u = ($t | Where-Object { $_.public_url -like 'https://*' } | Select-Object -First 1).public_url
if (-not $u) { $u = ($t | Select-Object -First 1).public_url }
"Public URL: $u"
"Health URL: $u/health"
已複製
